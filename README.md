# Tender Tracker

Тестовый backend-сервис для управления тендерами и историей изменения их статусов.

В рамках проекта выполняются:

- задание №6 — микросервис трекинга статусов тендеров;
- задание №9 — Docker / Docker Compose и CI через GitHub Actions.

Дополнительно планируется AI-анализ отдельных изменений статуса через внешний LLM API.
